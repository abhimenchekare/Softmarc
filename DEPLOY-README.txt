HOW TO UPDATE (2 min)
1. Open this folder and select ALL files (keep .npmrc + .gitignore too).
2. GitHub -> your repo -> Add file v Upload files -> drag everything -> Commit changes (Replace).
   (vendor/ and its 2 files must go into a vendor folder in the repo root - if you uploaded it before, updating the whole folder overwrites it.)
3. Hostinger -> Websites -> Manage -> Application -> Redeploy.
4. Open softmarcedu.in and press Ctrl+Shift+R (hard refresh).
5. Check: https://softmarcedu.in/vendor/pdf.min.js must show code, NOT 404.
   https://softmarcedu.in/server.js must say Forbidden.
